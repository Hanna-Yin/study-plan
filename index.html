第一周启动计划

高数从0 · 英语从0 ｜ 每天高数45min + 英语15min ｜ 做完即停，不求完美

☁️ 云同步设置（手机/电脑打卡一致）

粘贴 GitHub Token（仅存本机，不上传聊天）。建议用「仅本仓库」范围的 token。连接后，专家在对话里帮你打的卡、你记的错题，会自动同步到每台设备。

未连接：打卡仅存本机；专家已在本机为你预录 Day1/Day2。
仓库固定为 study-plan（自动用你的账号）。数据文件 study-data.json 含进度与错题。

☁️ 云同步已连接

已连接，打卡与错题自动同步。
每台设备（电脑浏览器 / 手机浏览器）首次打开输入一次 token 即可，之后自动连接，无需再输。想换 token 或断开时点下面按钮。

📐 高数（数二方向 · 从0起步 · 地基周）

每天节奏：前15min让AI讲解+例题 → 中间20min自己做3题 → 后10min核对。只做出1道也算赢。

🔤 英语（考研英二 · 从0起步）

每天：APP背15个最基础核心词 + 让AI用当日词造1个简单句并逐词讲。背了词+读了1句就算赢。若音标不会，前两天让AI顺带带过字母发音即可。

📒 错题本（复盘用 · 自动同步）

📖 学习回顾（随时回看已学内容）

这里把每天「学了什么、重点是什么」记下来，没网络也能翻。✓ 表示你已打卡完成。点下方标签切换「高数 / 英语」，页面更短更好找。

✏️ 每日练习（手机也能自测）

没有网络/不方便找专家时，就在这里自己做。点「显示答案」核对，做不出没关系——看懂答案也算学过。高数只做出1道也过关。
💡 进度默认存在本机。已连云同步时，专家帮你打的卡、你记的错题，手机/电脑打开同一网址自动一致。导出/导入可离线备份。
